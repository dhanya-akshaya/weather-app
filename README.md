# 🌦 Weather Forecast Website

A responsive weather forecasting web application that provides real-time weather information using WeatherAPI.

## 🚀 Live Demo
https://weather-app-4g7v.onrender.com

---

## 📌 Features

- 🌍 Search weather by city
- 🌡 Real-time temperature
- 🌥 Weather conditions
- 💧 Humidity details
- 🌬 Wind speed
- 🌙 Dark mode toggle
- ❌ Error handling for invalid cities
- 📱 Responsive modern UI

---

## 🛠 Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- WeatherAPI
- Render

---

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/dhanya-akshaya/weather-app.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open in browser:

```text
http://127.0.0.1:5000
```
